# Interface components

ANDOR Modular's interface is the ANDOR interface (`external/osp/andor-design-system/guide`),
in its own trim (ebonized ash and black anodized aluminium: [MATERIALS.md](MATERIALS.md)). It
is composed from the family's own code and rendered
assets, never copied and never redrawn:

| What | From | How Modular uses it |
|---|---|---|
| Tokens, materials, drawing (`design::colour`, `design::draw`, `CachedShadow`) | `external/osp/shared/andor-ui/Source/Design.*` | every colour, radius, shadow, knob, key, well and light |
| Look-and-feel, Inter and Outfit, type roles | `OspLookAndFeel.*` | knobs (`"mini"`, `"arc"`, `"thinArc"`, `"sprite"`), menus, combo boxes, text |
| Ceramic skin (housing, keys in four states, lenses, rail and fader cap, keybed, badges) | `CeramicSkin.*`, `AndorUiData` | the housing, every key, the macro lenses, VOLUME and the scene fader, the keyboard's bed, source badges |
| Ivory macro knob sprites | `SpriteKnobRenderer.*`, `AndorUiData` | the eight macros |
| Housing pack: ebonized ash cheeks, black anodized rails and end caps | `product/Resources/ebonized-ash-skin.zip`, generated by `tools/make_ebonized_ash_skin.py` over the shared housing render (MATERIALS.md) | `ui::applyMaterials()` (once per process); replaces the shared `housing` piece only |
| Device enamels and motifs | `external/analog/product/Source/FxIdentity.*` | the face of every processor and effect tile |
| The ROUTING board (face, wires with arrowheads, sage selection ring, group stack, OUTPUT terminal) | Analog's `FxRouting.cpp` (recipe) | the patch board |

`product/Source/Theme.h` only *names* what Modular uses and maps its modules onto that
vocabulary (`ui::lookFor`); it defines no colour, font, knob or key of its own. The one asset
Modular owns is its housing pack.

## Layout

One instrument on the family's 1448 × 1086 canvas, scaled to the window as one piece
(869 … 1810 px wide, fixed shape; `ui::layout`).

| Row | Parts |
|---|---|
| Header | ANDOR/MODULAR and its tagline · preset bar (‹ name ⌄ ›) · SAVE (cassette) · PATCH / PLAY keys · VOLUME · menu |
| Band, PATCH | the board down to the macro panel's foot: header (PATCH, counts, + ADD MODULE, ARRANGE, FIT, undo, redo), the canvas across its whole width, and, while a module is open, its rack along the foot (260 px; the canvas gives up height only) |
| Band, PLAY | ANDOR Analog's front panel: one source card for each sound source (one to four across, five or six in two rows of three), over the family's macro panel: eight macros, the scenes bay. No headline and no prose: the patch's name is in the preset bar |
| Keyboard row | PITCH wheel · 88 keys in their bed · voices card (POLY / MONO / LEGATO) · Evolve key |
| Footer | status line: what the last action did, with UNDO; otherwise voices, CPU, module and source counts, problems |

## What a module wears (`ui::lookFor`)

| Module | Face |
|---|---|
| Sound sources (`osc.*`, `src.*`) | a source card in miniature: cream ceramic, the layer badge (A copper, B slate, C sage, then again), knob arcs in that layer's colour |
| Processors and effects | their device's enamel and motif from Analog (DRIVE, MOVEMENT, ECHO, SPACE, CONVOLUTION, SPREAD / SATELLITE, COMPRESSOR, TONE → EQ, FX FILTER, PHASER, FLANGER / CHORUS, SHIFTER, RETRO; voice FILTER and MORPH from the synth racks) |
| Mixers, gains, switches, VOICE MIX, pan, meters | the UTILITY device (graphite enamel, meter-bridge motif) |
| Modulators (`ctl.*`), VCA | the modulation panel's cream face, the live accent |
| Note modules (`event.*`) | the arpeggiator's key face and amber |
| OUTPUT | the routing board's terminal |
| A group | the routing board's group summary: a graphite card on a fanned stack |

Ports are sockets on the tile's edges, told apart by shape and colour (never colour alone):
notes a triangle (amber), audio a dot (stereo ringed), control a diamond (moss), pitch a
barred diamond (mineral blue), gate / trigger / clock a square (verdigris). Wires are the
routing board's: 1.6 px warm grey with an arrowhead where the signal arrives, stereo 2.4 px,
notes amber, control sage, a modulation dashed and landing on its knob from above.

## Components

| Component | File | Notes |
|---|---|---|
| Editor | PluginEditor.* | the scaled surface and its layout; menus (patches, main with Size and Board scrolling, voices); shortcuts Cmd/Ctrl+K (Quick Add), Z / Shift+Z, S, E (Evolve), Ctrl+Tab (PATCH / PLAY); `dismissTopmost()`: Escape, one level per press (a drag, Quick Add's submenu, Quick Add, EVOLVE, the rack, the group, the selection), never an undo step |
| PresetBar, VolumeFader, PitchWheel, Keyboard, VoicesCard, RailFader | Frame.* | the family's parts (same pieces and recipes as `InstrumentFrame.cpp` / `MainSections.cpp`), bound to the patch; the keyboard and wheel reach the audio thread through a lock-free queue (`ModularProcessor::playFromInterface`), VOLUME through `Engine::setMasterDb` |
| Canvas + NodeView | Canvas.* | world pan/zoom (60–110 % fit, 30–250 % manual, zoom at cursor, pinch; scrolling pans with the gesture as delivered, `traditionalScroll` reverses), 8 px snap, rubber-band selection, Tab navigation, Delete, Cmd+D, Cmd+G, 0 (no F), Esc through the editor; tiles an edit moved glide to their place in 160 ms; the tile's face is cached (`setBufferedToImage`), only its glass repaints at 25 Hz; breadcrumbs inside groups |
| Tile | Canvas.cpp NodeView | name band (motif or badge, name, mode with its chevron or PER VOICE / GLOBAL / NOTES, M and S on sources and groups, status light = bypass), sockets (a count where several cables arrive), up to four mini knobs (only those that apply), the glass |
| Glass | Canvas.cpp `paintModuleDisplay` (tiles and the rack) | oscillator Hz, arp / sequencer steps, grain dots + position, recording waveform + playhead + status, both sides of a morph, satellite position, voices, host status, levels |
| Quick Add | QuickAdd.* | (Sources lead with the one SOURCE; a source type is listed and found as "SOURCE · TYPE": `rowName`) a compact menu at the pointer (root 268 px, rows 30 px): search, up to three recent modules, six categories (Sources, Processors, Controllers, Spatial, Effects, Utilities); a category's modules in a submenu beside it (hover 90 / 170 ms, or Right); typing: up to eight matches; arrows, Return (one module), Escape (one level); each row a swatch of the tile it adds, CPU and SOON tags; only compatible modules from a port or cable; kept inside the instrument |
| RackHost | RackHost.* | (also Analog's `FxRackSource` for that module: its running processor, impulse, rack memory and name) the family's `InstrumentHost` for exactly one module: a private parameter state under the rack's IDs, each bound to one of the module's parameters with its unit conversion (or to its light, a cable's depth, its TYPE); a control is `Session::setParam` on that module, one undo step per action; tempo, sample rate and the module's level from the running graph. | Rack library | Racks.*, ModuleRack.* | `createNativeRack`: ANDOR's own `EchoRack`, `SpaceRack`, `MovementRack` (shared, in Analog's faceplates, with the opt-in MIX knob) for ECHO, SPACE, MOVEMENT; ANDOR Analog's own effect rack (`createFxRackFor`: FxRack.cpp, compiled from the submodule with FxParameters and FxPresets) for the eight effects of its library, on Analog's FX parameter layout bound to the module by the table's names; for every other module a `ParameterRack` built from the family's parts in the module's identity, its controls planned by their real widths, and a picture specific to the device (docs/ADDENDUM_02_REUSE_AUDIT.md, section 4) |
| Cable drag | Canvas.* (`cableTargetAt`, `applyCable`, `paintOverChildren`) | rings on the sockets that could take the cable (accent); the target within 20 px or the module's face; a note at the pointer (the terminal face, board ink; the status line's red when refused) with the result of the edit tried on a copy of the patch; a refused drop's reason stays 4.5 s |
| Rack (the drawer) | Rack.* | hosts the family's `rack::Host` (full bleed, its X) for the module's native rack (224 px); the text that follows describes the plain rack, now only a group's: |
| Plain rack | Rack.* | one module across the board's foot, on the family's raised cream card: left, its face in miniature, name, type, where it runs, help, recording / plugin keys; centre, sections side by side (MODES: mode keys and toggles as ceramic keys; CONTROLS: knobs with their scale, label above and value below; STEPS: the 16-step graphite editor in the room that is left; MODULATED BY: depths on the rail), scrolling sideways only if a module has more than fits; right, LIVE: the front panel's display for a source, the tile's display at size for the rest; X.
